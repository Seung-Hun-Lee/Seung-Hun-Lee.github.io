## Local Preview

Use Jekyll preview instead of opening raw HTML files. Raw HTML or VSCode Live Server will not accurately render the Markdown, Liquid templates, Sass, layouts, and includes.

First-time setup, if needed:

```sh
gem install --user-install bundler:2.2.19
bundle _2.2.19_ config set path vendor/bundle
bundle _2.2.19_ install
```

Run the local preview server:

```sh
bundle _2.2.19_ exec jekyll liveserve --host 127.0.0.1 --port 4000
```

Open:

```text
http://127.0.0.1:4000
```

In this local checkout, a VSCode task may exist at `.vscode/tasks.json`. If present, `Cmd+Shift+B` runs the Jekyll preview task. Use `Simple Browser: Show` in VSCode with `http://127.0.0.1:4000` to preview inside VSCode.

## Git Workflow

Before editing:

```sh
git status --short
git pull
```

After editing:

```sh
git status --short
bundle _2.2.19_ exec jekyll build
git add <changed-files>
git commit -m "Update homepage"
git push
```

Only commit source files needed for the homepage. Avoid committing generated files, dependency folders, or local preview helpers.
